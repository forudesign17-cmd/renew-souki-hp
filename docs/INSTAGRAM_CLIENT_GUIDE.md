# Instagram 自動更新の設定（お客様向けのご案内）

ホームページの「INSTAGRAM」欄に、**Instagramの最新の投稿が毎日自動で表示される**ようにします。
一度設定すれば、あとはお客様に作業いただく必要はありません（投稿するだけで、翌日までにホームページへ反映されます）。

## お客様にしていただくこと（所要時間：約10分）

### ① Instagramを「プロアカウント」にする（すでにお済みなら不要）
Instagramアプリ → 設定 → アカウントの種類とツール → 「プロアカウントに切り替える」
（「ビジネス」か「クリエイター」のどちらでも問題ありません。無料です）

### ② 制作担当からの招待を承認する
制作担当が、ホームページ用の連携アプリにお客様のアカウントを「テスター」として招待します。
Instagramアプリ → 設定 → ウェブサイトのアクセス許可（または「アプリとウェブサイト」）→ **テスターの招待** → 承認

### ③ 一度だけ、ログインして許可する（画面共有で一緒に行うと確実です）
制作担当と通話や画面共有をしながら、表示される画面で Instagram にログインし、「許可」を押してください。
**パスワードを制作担当に伝える必要はありません**（ログインはお客様ご自身の画面で行います）。

以上で完了です。

## 制作担当が行うこと（お客様の作業ではありません）
- 連携アプリの作成とテスター招待
- ③の許可で発行される「接続用のコード（トークン）」を、ホームページの設定に登録
- 動作確認

## よくあるご質問
- **費用はかかりますか？** かかりません（Instagramの公式機能の範囲です）。
- **Instagramの運用や投稿に影響はありますか？** ありません。ホームページが「最新の投稿を読み取る」だけで、投稿やフォロー等の操作はしません。
- **途中でやめたくなったら？** Instagramの設定 → ウェブサイトのアクセス許可 から、いつでも連携を解除できます。解除してもホームページは、最後に取得した写真のまま表示され続けます。
- **投稿を非表示にしたい**ときは、Instagram側で投稿を非公開（アーカイブ）にしてください。翌日までにホームページからも外れます。

> 画面の名称は、Instagramアプリのバージョンによって少し異なる場合があります。見つからないときは、制作担当にお知らせください。
